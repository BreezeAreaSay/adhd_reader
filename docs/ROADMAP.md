# Дорожная карта

Идеи собраны по обзору инструментов для чтения при СДВГ ([Speechify: ADHD reading tools](https://speechify.com/ru/blog/adhd-reading-tools/)) — Helperbird, FocusEx, Glide, ADHD Reader, Speechify, Mindgrasp, Rewordify и др. — и отобраны по тому, насколько хорошо они ложатся на расширение браузера.

Оценка сложности: 🟢 — день-два, 🟡 — около недели, 🔴 — крупная задача. ✅ — сделано.

## Сделано

- ✅ **Бионическое чтение везде** (v0.1): динамический контент, Shadow DOM, фреймы, React/Vue, исключения сайтов.
- ✅ **Доводка бионики** (v0.2): saccade (каждое N-е слово), минимальная длина слова, усиленное выделение в уже жирном тексте, режим «только на выбранных сайтах», контекстное меню.
- ✅ **Фокус** (v0.2): линейка на строке и подсветка абзаца под курсором с затемнением остального.
- ✅ **Режим чтения** (v0.2): основной текст без отвлечений (Mozilla Readability), темы, размер, длина строки, полоса прогресса и оставшееся время.
- ✅ **Типографика и цвет** (v0.2): Atkinson Hyperlegible, Lexend, OpenDyslexic, PT Sans; межстрочный и межбуквенный интервал, интервал между словами; тонировка и приглушение страницы.
- ✅ **Быстрый старт** (v0.3): обычные страницы — сразу после разбора HTML, React/Vue — по сигналу об окончании гидратации; шрифты — до первой отрисовки.
- ✅ **Andika** (v0.3) — второй шрифт для удобного чтения с кириллицей (вместе с OpenDyslexic).

## Дальше

### Звук и темп
- 🟡 **Озвучивание с подсветкой текущего слова** — `chrome.tts`, регулируемая скорость, «читать отсюда», подсветка через CSS Custom Highlight API (без изменения DOM) (Speechify).
- 🟡 **Ведомое чтение** — подсветка, которая движется по тексту с заданной скоростью (слов в минуту), как в Glide; вариант — RSVP (по одному слову в центре экрана).
- 🟢 Индикатор прогресса и оставшееся время — сейчас есть в режиме чтения; можно добавить и для обычных страниц.

### Фокус
- 🟢 Перемещение линейки/абзаца клавишами ↑/↓ без мыши.
- 🟢 **Разбиение длинных абзацев** на короткие куски (ADHD Reader).
- 🟡 **Профили для отдельных сайтов** — свои настройки, например, для Википедии и для почты.

### Время и привычки
- 🟢 **Помодоро-таймер** для сессий чтения с мягкими напоминаниями о перерыве (FocusEx, Tiimo).
- 🟡 **Статистика** — сколько прочитано за день/неделю, цели (локально, без отправки данных).

### Помощь с пониманием (ИИ)
Требует ключа API (например, Claude) и явного согласия пользователя: текст страницы уходит во внешний сервис.
- 🟡 **Краткое содержание** страницы или выделенного фрагмента, «объясни проще» (Mindgrasp, Genio).
- 🟡 **Ключевые мысли и термины** — подсветка главного, словарик трудных слов (Rewordify, Actively Learn).
- 🔴 **Вопросы на понимание / карточки** по прочитанному (StudyFetch, Mindgrasp).

### Охват
- 🔴 **PDF** — свой просмотрщик на pdf.js: открывать PDF в странице расширения, где работают все режимы. Сейчас это самый заметный пробел.
- 🟡 **EPUB** — локальные книги в том же просмотрщике.
- 🟢 Шрифты внутри Shadow DOM без включённой бионики (сейчас корни Shadow DOM находит движок бионики).
- 🟡 **Firefox** — порт (Manifest V3 поддерживается; закрытые Shadow DOM там доступны через `element.openOrClosedShadowRoot()`).
- 🔴 **Canvas-приложения** (Google Docs, Figma) — технически недоступны для изменения текста; для Google Docs возможен обходной путь через режим чтения/экспорт.
