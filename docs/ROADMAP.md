# Дорожная карта

Этап 1 — бионическое чтение, работающее везде, — готов. Ниже идеи для следующих этапов, сгруппированные по смыслу. Они собраны по обзору инструментов для чтения при СДВГ ([Speechify: ADHD reading tools](https://speechify.com/ru/blog/adhd-reading-tools/)) — Helperbird, FocusEx, Glide, ADHD Reader, Speechify, Mindgrasp, Rewordify и др. — и отобраны по тому, насколько хорошо они ложатся на расширение браузера.

Оценка сложности: 🟢 — день-два, 🟡 — около недели, 🔴 — крупная задача.

## 1. Доводка бионического режима

- 🟢 **Saccade** — выделять не каждое слово, а каждое 2-е/3-е (как в оригинальном Bionic Reading).
- 🟢 **Минимальная длина слова** — не выделять предлоги и короткие слова.
- 🟢 **Относительная насыщенность** — для уже жирного текста (заголовки) брать ещё более жирное начертание или усиливать затемнение остатка.
- 🟢 **Режим «только на выбранных сайтах»** (список разрешённых вместо списка исключений).
- 🟡 **Профили для отдельных сайтов** — свои настройки, например, для Википедии и для почты.
- 🟢 **Контекстное меню** — «применить только к выделенному фрагменту», «выключить на этом сайте».

## 2. Фокус и меньше отвлечений

- 🟡 **Линейка чтения / фокус на строке** — подсветка полосы текущей строки, затемнение остального; следует за курсором или управляется клавишами (Helperbird, ADHD Reader).
- 🟡 **Фокус на абзаце** — затемнение всего, кроме абзаца под курсором; переход по абзацам клавишами ↑/↓.
- 🟡 **Режим чтения без отвлечений** — извлечение основного текста страницы (библиотека Mozilla Readability), без рекламы, сайдбаров и всплывашек (FocusEx).
- 🟢 **Типографика** — шрифты для лёгкого чтения (Lexend, Atkinson Hyperlegible, OpenDyslexic), размер, межстрочный и межбуквенный интервал, ширина колонки.
- 🟢 **Цветной фон / тонировка и приглушение экрана** — снижает зрительную нагрузку (Helperbird).
- 🟢 **Разбиение длинных абзацев** на короткие куски (ADHD Reader).

## 3. Звук и темп

- 🟡 **Озвучивание с подсветкой текущего слова** — `chrome.tts` / Web Speech API, регулируемая скорость, «читать отсюда» (Speechify).
- 🟡 **Ведомое чтение** — подсветка, которая движется по тексту с заданной скоростью (слов в минуту), как в Glide; вариант — RSVP (по одному слову в центре экрана).
- 🟢 **Индикатор прогресса** и «осталось ~N минут чтения».

## 4. Время и привычки

- 🟢 **Помодоро-таймер** для сессий чтения с мягкими напоминаниями о перерыве (FocusEx, Tiimo).
- 🟡 **Статистика** — сколько прочитано за день/неделю, цели (локально, без отправки данных).

## 5. Помощь с пониманием (ИИ)

Требует ключа API (например, Claude) и явного согласия пользователя: текст страницы уходит во внешний сервис.

- 🟡 **Краткое содержание** страницы или выделенного фрагмента, «объясни проще» (Mindgrasp, Genio).
- 🟡 **Ключевые мысли и термины** — подсветка главного, словарик трудных слов (Rewordify, Actively Learn).
- 🔴 **Вопросы на понимание / карточки** по прочитанному (StudyFetch, Mindgrasp).

## 6. Охват

- 🔴 **PDF** — свой просмотрщик на pdf.js: открывать PDF в странице расширения, где работают все режимы. Сейчас это самый заметный пробел.
- 🟡 **EPUB** — локальные книги в том же просмотрщике.
- 🟡 **Firefox** — порт (Manifest V3 поддерживается; закрытые Shadow DOM там доступны через `element.openOrClosedShadowRoot()`).
- 🔴 **Canvas-приложения** (Google Docs, Figma) — технически недоступны для изменения текста; для Google Docs возможен обходной путь через режим чтения/экспорт.
